PDF Merger App
A simple, user‑friendly Python application that merges multiple PDF files into a single PDF, automatically sorts them alphabetically, and inserts bookmarks for each merged file.

🚀 Features
Add individual PDF files through the UI

Add an entire folder of PDFs at once

Automatically sort selected PDFs in alphabetical order before merging

Generate bookmarks for each file inside the merged PDF

Clean, simple graphical interface (Tkinter)

Output a single merged PDF with preserved order and structure
